HOW TO LAUNCH

Host mode (TV / laptop): open this page and press Host on this screen (or load ?host). A QR code and 4-letter room code appear.

Controller mode (phones): scan the TV's QR code (opens ?room=ABCD) or press Join as player and type the code. You get two giant buttons: TRUE and FALSE.

Rooms & QR: the TV creates an online room (Firebase) and shows a QR code that opens this page with the room code in the address, e.g. …/index.html#ABCD. Phones just scan it — no install, no same-Wi-Fi requirement. The page itself must be hosted at a normal web address (like your other game).

Rules: 3 lives each. Every 5 prompts the rule flips (Does it fly? / Does it swim? / Has wheels?). Answer TRUE or FALSE about the word on the TV before the 2¼-second bar runs out. Correct = +100 (+50 if under 1 s). Wrong or too slow = lose a heart. Last one standing wins — or highest score after 20 prompts.
